Laboratório Comparativo: Vanilla JavaScript (ES6+) vs jQuery

Veja lado a lado como as instruções equivalentes são escritas em JavaScript nativo e na biblioteca jQuery.
Por que aprender ambos na disciplina? O jQuery revolucionou a Web ao unificar a sintaxe e resolver inconsistências entre navegadores legados (como IE6/7/8). No entanto, com a consolidação dos padrões ES6+ (como querySelector, fetch, e métodos funcionais de array), o Vanilla JavaScript tornou-se rápido, moderno e autossuficiente. Compreender essa equivalência é essencial para manutenção de sistemas legados e domínio do ecossistema front-end!
Caso 1

Seleção e Texto

Capturar um elemento pelo ID e atualizar seu texto interno.

Vanilla JS (Nativo) 
// Seleciona e altera texto
const el = document.getElementById('countTotal');
el.textContent = '10';
jQuery 
// Sintaxe abreviada com $
$('#countTotal').text('10');
Caso 2

Escuta de Eventos

Adicionar um ouvinte para cliques e evitar o comportamento padrão.

Vanilla JS (Nativo) 
// addEventListener padrão
btn.addEventListener('click', (event) => {
  event.preventDefault();
  console.log('Clicado!');
});
jQuery 
// Método .on() ou .click()
$('button').on('click', function(event) {
  event.preventDefault();
  console.log('Clicado!');
});
Caso 3

Animação & Ocultação

Fazer um elemento desaparecer suavemente da interface.

Vanilla JS (Nativo) 
// Transição CSS + remoção
el.style.transition = 'opacity 0.3s';
el.style.opacity = '0';
setTimeout(() => el.remove(), 300);
jQuery 
// Método nativo fadeOut()
$('#demoBox').fadeOut(300, function() {
  $(this).remove();
});
