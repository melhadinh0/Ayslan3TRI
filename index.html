Laboratório Comparativo: Vanilla JavaScript (ES6+) vs jQuery

Entenda a equivalência de sintaxe, o papel histórico do jQuery e as razões da consolidação do JavaScript nativo moderno.

Por que o Vanilla JS superou o jQuery em projetos modernos? O jQuery (2006) foi vital para padronizar o DOM em navegadores antigos e simplificar requisições AJAX. A partir de 2015, com as especificações ECMAScript 6+ e APIs modernas (como querySelector, fetch, classList e métodos funcionais de arrays), os navegadores alcançaram compatibilidade nativa de alta performance, dispensando o peso de uma biblioteca externa de 30KB+ na maioria das aplicações contemporâneas.
